# Rule: Keep the README Index in Sync

The root [README.md](../README.md) is the index page of this course, like the table of contents of a textbook. It must always list every chapter with a link and a short description.

Whenever a learning file is added, or an existing chapter changes significantly:

1. **Read the module's actual code** — imports, functions, comments, section headers. Never infer the topic from the filename.
2. Give the chapter a **descriptive topic title** ("Lambda Triggers & Event Payloads", not "Chapter 4").
3. Write a **one-row summary** naming the specific functions/APIs covered, so the index can be used to find where a given call is taught.
4. Insert or update the row in **numerical order** with a working relative link.
5. Mark a module that is only a stub as "Work in Progress" and revisit the row later.
6. **Non-chapter resources** (data folders, helper scripts, notes) go in the separate "Setup & Extras" table.

Do this **proactively** — if you notice during any task that a chapter is missing from or stale in the index, fix it as part of that work and tell the user.
